# Avatara — AI Avatar Landing Page

A responsive white and sky-blue landing page starter for an AI avatar product.

## Stack

- React 18 + TypeScript
- Vite
- Lucide icons
- Custom responsive CSS

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Before launch

- Replace the temporary Avatara wordmark and copy with your product branding.
- Connect the primary calls to action to your avatar creation and authentication flows.
- Add your final pricing, privacy policy, terms, and contact links.
- Replace stock photography with approved product and avatar imagery.
- Review image and voice consent, privacy, storage, and deletion policies before accepting uploads.
